# Forecasting Application

This Streamlit application provides time series forecasting capabilities.

## Features

- Upload your own time series data
- Configure forecasting parameters
- Visualize forecasting results

## How to Use

1. Upload a CSV file containing time series data
2. Select the appropriate time and value columns
3. Adjust forecasting parameters
4. View the forecast results and visualizations
